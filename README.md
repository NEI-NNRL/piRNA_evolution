# piRNA_evolution
This is supplimental code for "Conserved host genes act as anchors for fast-evolving piRNA clusters via promoter hijacking".
It is not a install-and-use software package. Some modifications migh be required to run on your computer.

Install NCBI Datasets as binary "~/scripts/datasets".

Running would require making changes in "notebooks/MG3.functions1.R", add your Entrez API key, change the paths.

*"Compara.115.protein_default.homologies.tsv"

*"Compara.112.protein_default.homologies.tsv"
